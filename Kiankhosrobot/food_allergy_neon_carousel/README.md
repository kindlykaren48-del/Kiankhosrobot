# کاروسل نئونی: معرفی غذاهای آلرژی‌زا برای کودک

مجموعهٔ فارسیِ ۶ اسلایدی با پالت نئونیِ چندرنگ (سرمه‌ای تیره، فیروزه‌ای، صورتی، بنفش، لیمویی و نارنجی).

- انتشار: `slide_01.png` تا `slide_06.png`
- اندازهٔ هر اسلاید: ۱۰۸۰×۱۳۵۰ پیکسل، نسبت ۴:۵
- `carousel.pdf`: پیش‌نمایش چندصفحه‌ای
- `carousel_assets.zip`: شش PNG به‌ترتیب، کپشن و منابع
- `caption.txt`: کپشن پیشنهادی
- `sources.txt`: منابع بازبینی محتوای پزشکی

**نکتهٔ دقت:** متن جلد به‌جای تعمیمِ «بیشتر واکنش‌ها اولین‌بار هنگام معرفی رخ می‌دهند»، می‌گوید واکنش می‌تواند پس از مواجهه با غذا آشکار شود و زمان/شدت آن یکسان نیست. راهنمای بادام‌زمینی برای شیرخواران پرخطر نیز به مشورت با پزشک ارجاع می‌دهد.

این محتوا آموزشی است و جایگزین توصیهٔ پزشک کودک نمی‌شود.
