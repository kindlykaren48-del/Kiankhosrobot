# کاروسل نئونی با چیدمان سبک ریل

شش اسلاید عمودیِ مستقل، با قالب بصری ریل‌های آموزشی مخزن: شماره و تیتر در بالا، نقطه‌های پیشرفت، کادر نکات، و کارت تصویرِ بدون نوشته در پایین.

- اسلایدها: `slide_01.png` تا `slide_06.png`
- ابعاد: ۱۰۸۰×۱۹۲۰ پیکسل، نسبت ۹:۱۶
- `carousel.pdf`: پیش‌نمایش شش‌صفحه‌ای
- `carousel_assets.zip`: فقط شش PNG آمادهٔ بارگذاری، به‌ترتیب
- `sources.txt`: منابع محتوای پزشکی
- `build_carousel.py`: اسکریپت ساخت اسلایدها

این‌ها اسلایدهای تصویری‌اند؛ ویدیو یا نریشن در این تحویل وجود ندارد.
