# کاروسل: زخم‌ها و عفونت‌های پوست سر در کودکان

مجموعه‌ای فارسی و ۶ اسلایدی با پالت زرشکی، نعناعی و لیمویی.

- فرمت انتشار: شش فایل `slide_01.png` تا `slide_06.png`
- اندازهٔ هر اسلاید: ۱۰۸۰×۱۳۵۰ پیکسل، نسبت ۴:۵
- `carousel.pdf`: پیش‌نمایش چندصفحه‌ای
- `carousel_assets.zip`: اسلایدهای PNG به‌همراه کپشن و منابع
- `caption.txt`: کپشن پیشنهادی
- `sources.txt`: منابع بازبینی محتوای پزشکی

برای چیدمان اینستاگرام، تصاویر را به‌ترتیب شماره بارگذاری کنید. متن آموزشی عمومی است؛ برای تشخیص و درمان کودک با پزشک مشورت شود.
